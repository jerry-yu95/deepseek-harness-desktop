DEEPSEEK HARNESS DESKTOP 0.1.1

把原来的网页端装进 EXE，但不重写它

佬友们好，前段时间一直在使用 DeepSeek Harness 的网页端。功能很完整，但每次都要先启动本地主机、再打开浏览器；插件、技能和不同 profile 多起来以后，管理起来也有些零散。

所以我做了一个 Windows 桌面版。它不是仿照网页重新写一套界面，而是在本机回环地址启动官方 @deepseek-ai/dsh 运行时，再把原版 Web UI 无损加载进 Electron 窗口。网页端已有的交互、插件和皮肤都继续使用同一套实现。

现在保留了什么

  • 任务看板、Git 图谱、右侧文件与变更面板、SSH、移动端远程、实时统计和宠物等原有功能；
  • 21 个 UI 插件和 9 款可选皮肤，包括 Miku、Trading、Windows XP、Minecraft 等主题；
  • 原版插件机制，以及项目技能、DSH 技能和 Agents 技能的发现与导入；
  • 官方 DSH、pnpm 和原生依赖随安装包提供，不要求用户另装 Node.js。

桌面版使用独立的 desktop profile，不会覆盖已经存在的 DSH 配置；本地主机默认只监听回环地址。
