## GitHub announcement

DeepSeek Harness Desktop 0.1.0 is now available for Windows.

This is a lossless desktop port of the original DSH Web surface, not a rewrite. The EXE starts the official DSH host locally, keeps the complete plugin and skin collection, and adds native lifecycle management, recovery, hardened navigation, rotating sanitized logs, and an Extension Dock for plugins and skills.

The source, Windows x64 installer, SHA-256 checksums, architecture notes, and reproducible tests are public. The release is community-built and currently unsigned, so download it only from the official repository Release page.

Repository: https://github.com/jerry-yu95/deepseek-harness-desktop
