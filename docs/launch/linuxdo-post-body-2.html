桌面能力、验证与当前限制

不只是套一个窗口，也把桌面端该有的基础补齐了

  • 扩展坞：可以查看内置插件、安装或回滚社区 bundle，并安全导入项目和用户技能；
  • 生命周期：支持单实例、窗口状态恢复、正常退出、有限崩溃恢复和启动诊断；
  • 安全边界：启用渲染进程沙箱与上下文隔离，限制导航、权限和下载，并对日志进行脱敏与轮转；
  • 原生窗口体验：暗色顶栏与原界面连成一体，同时保留 Windows 原生最小化、最大化、关闭、缩放和 Snap 布局。

我做过的验证

当前版本通过了 30 项桌面测试、41 个运行包审计，并分别使用开发运行时和最终打包 EXE 做过全新 profile 实启测试。GitHub CI 和 Release 打包流水线也已经跑通。

先把不足说在前面

目前只提供 Windows x64。因为安装包内带完整 DSH 与 Node 运行环境，安装器约 190.84 MiB，解包后约 606.83 MiB，并不是轻量客户端。社区构建暂时也没有商业代码签名，首次运行可能遇到 SmartScreen 的“未知发布者”提示。
