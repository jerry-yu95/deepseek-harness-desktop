## Install-acceptance regression addendum

The first 0.1.40 DMG exposed three integration gaps. They are included in the same unpublished RC before a replacement installer is produced:

- `mcp.json` and other safe text filenames override an erroneous official-image MIME report, while strict UTF-8/binary validation still fails closed;
- saved custom models expose a reversible image-input declaration without changing official packages or claiming provider-side multimodal verification;
- the Extension Center hides the official semantic `[data-composer-seat]`, including the sticky composer rendered outside the direct conversation-pane children.

Targeted acceptance after the addendum: text-context tests, Extension Center tests, desktop tests, full workspace typecheck/test, and a replacement arm64 package verification.

### Finder clipboard regression follow-up

Installed-app testing found a second macOS path: copying `mcp.json` in Finder placed both a native file reference and a PNG icon preview on the clipboard. The Electron shell preferred the image and synthesized `pasted-image.png` before the renderer could see the JSON filename. The follow-up makes native local file references (`public.file-url`, `text/uri-list`, and Finder's filename plist) take precedence. It reads at most four explicitly pasted files, never exposes source directories, rejects symbolic links, and preserves the renderer's existing type, size, UTF-8, and redaction checks. Acceptance requires the generated browser event to contain `mcp.json` and its JSON bytes, never the Finder icon PNG.

A later real-Finder probe exposed one more detail: Electron returned both the real path and an opaque `/.file/id=...` alias for the same file. The alias was classified as a second unsupported file, rejecting the whole batch. The RC now drops that opaque alias, accepts generic binary MIME for an allowlisted safe-text extension, and shares one capture listener across repeated client mounts. An isolated GUI acceptance copied a real `mcp.json` in Finder and pasted it with Cmd+V; the composer received one JSON text block and redacted its Authorization value.
