# DSH 渠道机器人

桌面版内置并锁定了社区成熟插件 `@xmanrui/dsh-im@0.7.1`，由它负责渠道连接和凭据管理。当前支持：

- 微信 iLink
- 飞书 / Lark
- 企业微信智能机器人
- QQ 机器人
- 钉钉、Telegram、Discord、Slack、WhatsApp

## 使用方式

启动桌面版后进入「设置 → 插件 → IM 机器人」，选择渠道并使用二维码或手动凭据完成绑定。插件会将密钥交给 DSH 的凭据服务保存，配置文件仅保存引用，不需要在终端里导出 API Secret。

每个机器人可以绑定独立工作区和 Harness 会话。群聊使用前建议配置白名单，并只给可信用户开放 `/session` 等会话管理命令。

## 来源和安全边界

这是社区插件，不是 DeepSeek 官方内核的一部分。桌面版固定使用 `0.7.1`，并保留上游插件随附的许可证及第三方声明；升级前应继续审查新版本。

插件的机器人连接需要访问对应平台的官方 API / WebSocket 服务。桌面应用不会替用户创建公网回调；具体渠道仍需在飞书、企业微信、QQ 或微信侧完成应用/机器人权限配置。

## 与旧版自定义网关的变化

旧版曾在 `dsh-remote-web-ui` 内通过环境变量启动临时网关，只覆盖飞书、企业微信和微信，且没有桌面端凭据配置界面。现在已移除那套临时代码，避免与 `dsh-im` 同时登录同一机器人导致重复回复；移动端远程控制仍由 `dsh-remote-web-ui` 独立提供。
