## Status vocabulary

2026-09-13 用户随后授权更新 arm64 DMG：镜像、ad-hoc 签名、218 运行包及十份关键文件一致性检查通过，直接从只读 DMG 启动的知识阅读 7/7、通用验收 5/5 通过。新包路径、SHA-256、证据标识及平台边界见 [发布验收报告](0.1.45-release-report.md)。旧 DMG 不变，真实文章/模型仍待用户验证。

- `PASS`: scenario met its expected result.
- `FAIL`: product-owned failure reproduced by the scenario.
- `BLOCKED_EXTERNAL`: requires a user account, enterprise network or provider authorization.
- `ENVIRONMENTAL`: test runner or host restriction; must be re-run before release decisions.
- `LOCAL_PASS`: passed in the dated local checkout and platform only; hosted CI, installers and live accounts are separate gates.
- `NOT_RUN`: no current execution evidence; configuration or historical success is insufficient.

## Evidence rules

- Evidence must include command, commit, platform and aggregate result.
- For an uncommitted checkout, identify the base commit and dirty state explicitly; do not claim the base SHA contains the tested changes.
- Electron evidence uses unique directories under `DSH_E2E_ARTIFACTS_ROOT`, aggregate result JSON and synthetic screenshots/geometry only. CI retention is seven days; temporary local evidence is not a permanent release archive.
- Screenshots must use invented data and a disposable profile.
- Never include secrets, authorization headers, Cookies, internal URLs, local usernames or private article text.
