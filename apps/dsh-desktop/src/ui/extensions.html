扩展坞

管理社区插件与本地技能。内置能力受到保护，所有改动只作用于 desktop profile。

01

Cordis 插件

安装注册表中的 DSH bundle。安装前请确认来源可信；插件拥有宿主进程权限。

高级功能：从 NPM 安装社区插件

仅供知道插件包名的高级用户使用，这不是应用更新入口。

02

技能目录

遵循官方五级优先顺序扫描。导入后由 DSH watcher 自动刷新，无需重启。

03

皮肤中心

桌面版已内置 9 款 dsh-web-ui 皮肤。进入 Harness 后打开“设置 → 插件配置 → Web UI 插件 → 皮肤中心”，可以先试穿，再决定是否应用。

04
