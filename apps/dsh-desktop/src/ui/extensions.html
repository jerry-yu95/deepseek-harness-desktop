JIWEI / EXTENSION DOCK

扩展坞

插件扩展运行时，技能沉淀工作方法，连接器提供外部工具与数据。三类能力独立管理。

01

Cordis 插件

安装注册表中的 DSH bundle。安装前请确认来源可信；插件拥有宿主进程权限。

高级功能：从 NPM 安装社区插件

仅供知道插件包名的高级用户使用，这不是应用更新入口。

02

技能目录

遵循官方五级优先顺序扫描。导入后由 DSH watcher 自动刷新，无需重启。

Skill Studio · 创建可被 Harness 自动发现的 SKILL.md
保存到用户 DSH Skill 根目录；当前 Harness watcher 会自动发现。

03

连接器中心

第一阶段支持自定义 MCP 与 HTTP 连接器注册、凭证引用和健康检查。后续平台适配器复用同一注册表。

＋ 自定义连接器

本阶段不在注册表保存密钥，只记录环境变量名称；正式平台连接器将接入系统安全凭证服务。

MCP 保存后会通过官方 dsh-mcp-client 注册为 Agent 原生工具，并安全重载 Harness。

04

自定义皮肤

进入 Harness 后打开“设置 → 插件配置 → Web UI 插件 → 自定义皮肤”，上传图片后由桌面端自动选择可读配色与遮罩。

图片驱动自动适配亮色 / 暗色一键恢复默认

自定义皮肤只改变背景、配色与遮罩，不会更换模型、Agent 预设、工具或权限。

05

更新中心

桌面应用跟随本项目 GitHub Releases；官方 DSH 内核使用独立备份、验证与回滚流程。
